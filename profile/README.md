> One named Swift To-Do List tree. Finish the reminder. Leave a note the next list can read.

## How Swift To-Do List Sits

Swift To-Do List does not replace the calendar, the mail client, or the stickies that already fall off the monitor. It sits beside them as a named to-do desk for one job: which task tree is live, which reminders still match the named list, and what the next person should read before the weekly tasks return.

## Traffic Light

| Signal | On the Swift To-Do List board | What you do |
|--------|----------------------|-------------|
| Green | Named list, short live reminder set | Continue the same task tree |
| Amber | Two weeks mixed on one named list | Split the tree before you pin |
| Red | No title, no note, stickies on the monitor | Stop and name the list first |
| Clear | Handoff written, live items few | Close Swift To-Do List and leave the desk |

## Open Order

1. Open the last Swift To-Do List named list, not a new empty task tree.
2. Read the reminders and the last handoff.
3. Finish one visible to-do desk item inside Swift To-Do List.
4. Write what changed, then close with fewer fallen stickies than you found.

## After a Week

A week in Swift To-Do List is not a larger sticky pile. It is the same title, a shorter live task tree, and a note that still makes sense when the weekly tasks return. Take finished items off the live set so the next visit starts on the named list that is still open.

## Sign-off

- [ ] The Swift To-Do List workspace name is short enough to scan
- [ ] Only live tasks sit on the tree
- [ ] A second person can read the list handoff
- [ ] The last Swift To-Do List named list still opens after a restart

## Field Note

Swift To-Do List is easier to trust when the to-do desk stays smaller than the sticky pile it came from. Name the list, keep the live reminders, finish one visible item, and write what changed.
